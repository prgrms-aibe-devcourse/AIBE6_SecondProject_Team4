Project Overview

피트니스 트레이너
매칭 플랫폼

헬스장은 많지만 나에게 맞는 트레이너를 찾기 어렵습니다.

FitMate는 트레이너와 회원을 스마트하게 연결해 더 효율적인 운동 경험을 제공합니다.

트러블슈팅

1

Google OAuth2 nameAttributeKey 오류

문제 구글 로그인 시 nameAttributeKey를 잘못 지정해 사용자 정보 파싱이 실패하며 로그인 불가
해결 구글 UserInfo 응답 구조를 분석해 sub 대신 email을 nameAttributeKey로 설정, OAuth2UserInfo 파싱 로직 수정
2

소셜 로그인 후 ERR_TOO_MANY_REDIRECTS

문제 소셜 로그인 성공 후 리다이렉트 루프 발생 → ERR_TOO_MANY_REDIRECTS 오류
해결 SecurityFilterChain successHandler에서 JWT 쿠키 설정 후 단일 리다이렉트, 중복 필터 및 로직 제거로 루프 차단
3

data.sql 한글 인코딩 깨짐

문제 초기 데이터 삽입 시 data.sql의 한글이 깨져 DB에 ???로 삽입됨
해결 파일 인코딩을 UTF-8로 저장 + datasource URL에 characterEncoding=UTF-8 파라미터 추가
4

배포 후 redirect URI가 localhost로 이동

문제 EC2 배포 후에도 OAuth2 redirect URI가 localhost를 참조해 소셜 로그인 실패
해결 카카오·구글 콘솔에 EC2 도메인 추가, application-prod.yml에 프로덕션 redirect URI 별도 설정
